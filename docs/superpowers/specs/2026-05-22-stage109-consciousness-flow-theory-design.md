# Stage109 Consciousness Flow Theory Design

## Context

Stages 104-108 made the provider-above interaction path visible:

- local semantic attractors;
- finite provider packet planning;
- provider tool affordance adaptation;
- packet-return-delta loops;
- external expression streams.

The theory now needs to become a structured artifact with hypotheses and
metrics, not only prose.

## Design

Stage109 builds a `consciousness_flow_theory` frame from a Stage108 stream.

The frame contains:

- core thesis;
- claim boundary;
- axioms;
- Stage104-108 mechanism map;
- internal/external bridge;
- falsifiable hypotheses;
- measurement plan;
- literature bridge;
- publishable contribution.

## Theory Boundary

The frame explicitly does not claim subjective consciousness. It claims that
provider-above finite-context control can simulate measurable consciousness-flow
properties: continuity, grounded perturbation, compression, and expression
granularity.

## Metrics

- `source_event_coverage`
- `delta_retention`
- `grounding_ratio`
- `expression_granularity_fit`
- `premature_expression_rate`

## CLI

`stage109-consciousness-theory` builds Stage105, Stage107, Stage108, and then
emits the theory frame for the same query.

## Tests

- Stage104-108 are mapped to concrete mechanisms.
- Hypotheses are falsifiable and tied to metrics.
- Expression decoupling is preserved.
- Literature bridge includes core related work.
- CLI emits Stage109 and Stage108 linkage.
